# Original ST page goldens

These lossless320×200RGBA PNGs are generated by executing the original recovered68000 page routines. They are independent of the TypeScript renderer. `source-pages.json` records raw RGBA SHA-256 values, palette words, and source stop addresses; the PNG container bytes are not used as the pixel golden.

```sh
python tools/graphics/atari-st-pages.py /path/to/source-files /path/to/original-main.bin /tmp/st-pages
```

The optional offline probe requires `machine68k`. It validates the original program, original disk files, and bundled TOS8×8 font. GEMDOS9 VT52 output is implemented with that font; XBIOS palette calls are captured. Audio routines and waits are skipped. It initializes the page buffers directly and executes the original copy, border, logo, scrolling, and text routines. No CPU emulation is included in the website or normal build.

Title and name fixtures precede animated stars and user input. The name field contains the native ten dots at(120,128), ink11; entered characters replace these cells without forcing case. Game Over and bravery fixtures use a blank stage0 framebuffer so the native window and stage palette can be compared independently of game state. Bravery shows nine lives and the unarmored10000-point bonus. Roulette starts with its pointer at(208,104). Name, roulette and ending use a full320×192 border and logo at(80,24); the ordinary title uses logo(80,18).

Score fixture suffixes count calls to the original one-pixel scrolling routine. The first record becomes visible at step9; at step145 its top is55. The native clip is x80..239,y54..191. `scores-cycles.json` records68000 cycles excluding OS text rendering and the VBL wait. Ordinary nonprinting steps require226780cycles, longer than one160212-cyclePAL interval; printing steps require139532cycles plus the OS font cost. Exact wall-clock cadence also depends on that OS cost and VBL alignment.
